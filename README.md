# Paradise Nursery Shopping Application

Paradise Nursery is an online houseplant shopping application built with React and Redux Toolkit.

The application allows users to browse a variety of houseplants grouped into different categories, add plants to a shopping cart, update item quantities, remove products, and view the total cost of their cart.

## Features

- Paradise Nursery landing page
- Company information
- Get Started button
- Houseplants grouped into multiple categories
- Plant image, name, and price
- Add to Cart functionality
- Dynamic shopping cart counter
- Redux Toolkit state management
- Increase and decrease item quantities
- Delete items from the cart
- Total plant count
- Total cart cost
- Continue Shopping button
- Checkout button with a Coming Soon message

## Technologies Used

- React
- Redux Toolkit
- React Redux
- Vite
- JavaScript
- CSS
- GitHub Pages
